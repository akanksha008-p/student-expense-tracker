Student Expense Tracker 💰

A simple and responsive web application for tracking daily expenses, managing a monthly budget, and understanding spending habits.

🌐 Live Demo

Open the live website from the About section of this repository.

✨ Features

- ➕ Add expenses with description, amount, date, and category
- 💰 Set and save a monthly budget
- 📊 View total spending
- 📈 Visualize spending with a bar chart
- 🔽 Filter expenses by category
- ✏️ Edit expenses
- 🗑️ Delete expenses
- 🌙 Dark and Light Mode
- 💾 Save data using browser localStorage
- 📱 Responsive design for mobile devices

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser localStorage
